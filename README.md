# LangChain Gemini Chatbot + PDF RAG

This is a **Streamlit chatbot** using LangChain and Google Gemini for AI chat, with PDF Retrieval-Augmented Generation (RAG).

## Features
- Chat with Gemini AI
- Upload PDFs to query using RAG
- Supports embeddings with HuggingFace
- Streamlit UI with pinned input box
