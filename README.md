# LangChain Gemini Chatbot + PDF RAG

This is a **Streamlit-based chatbot** using **LangChain** and **Google Gemini** for AI chat, with **PDF Retrieval-Augmented Generation (RAG)** support.  
Users can interact with the AI and query information directly from uploaded PDF documents.

## Features
- Chat with **Gemini AI** for natural conversation
- Upload **PDFs** and query them using **RAG**
- Supports **embeddings** with **HuggingFace SentenceTransformers**
- Streamlit UI with **pinned chat input** for better user experience
- Session memory to maintain conversation context
